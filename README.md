# 🚀 IDEALAUNCH

### Discover Ideas. Build the Future.

IDEALAUNCH is a Startup Ideas Discovery Platform that helps users discover, search, filter, and save startup ideas.

## ✨ Features

- Login & Signup
- Session-based Authentication
- Dashboard
- Explore Startup Ideas
- Search & Category Filter
- Save/Favourite Ideas
- Idea Details
- User Profile
- Logout
- Responsive Design

## 🛠️ Technologies

- React
- Next.js
- JavaScript
- Tailwind CSS
- sessionStorage
- localStorage

## 🎨 UI Design

Minimalism
